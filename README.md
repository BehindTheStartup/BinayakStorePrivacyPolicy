# Binayak Store Privacy Policy

This repository hosts the privacy policy for Binayak Store mobile applications (Admin and Customer apps), designed to be publicly accessible and linked in Google Play Store and Apple App Store submissions.

## 📄 Files

- **`privacy-policy.html`** - Main privacy policy page (self-contained, mobile-responsive)
- **`index.html`** - Auto-redirects to privacy-policy.html for cleaner URLs

## 🌐 Live URL

Once GitHub Pages is enabled, the privacy policy will be accessible at:
```
https://<your-username>.github.io/BinayakStorePrivacyPolicy/privacy-policy.html
```

Or simply:
```
https://<your-username>.github.io/BinayakStorePrivacyPolicy/
```
(Auto-redirects to the policy page)

## 🚀 Setup GitHub Pages

1. **Make sure this repo is PUBLIC** (required for free GitHub Pages)
2. Go to **Settings → Pages** on GitHub
3. Set **Source** to:
   - Branch: `main`
   - Folder: `/ (root)`
4. Click **Save**
5. Wait 1-2 minutes for deployment
6. GitHub will show your live URL

## 📱 Linking in App Stores

### Google Play Store
1. Open **Play Console** → Your App → **App content** → **Privacy policy**
2. Enter the GitHub Pages URL
3. Save

### Apple App Store
1. Open **App Store Connect** → Your App → **App Information** → **Privacy Policy URL**
2. Enter the GitHub Pages URL
3. Save

## ✏️ Updating the Policy

**You can update the privacy policy anytime without app resubmission:**

1. Edit `privacy-policy.html` (update date, email, practices, etc.)
2. Commit and push changes:
   ```bash
   git add privacy-policy.html
   git commit -m "Update privacy policy"
   git push origin main
   ```
3. Changes go live automatically within 1-2 minutes
4. No need to notify Google/Apple or update store listings
